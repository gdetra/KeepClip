# Microsoft Store listing — English (United States)

## Product name

KeepClip

## Short description

Keep text, images and file references in a local clipboard history, just a keyboard shortcut away.

## Description

Copy once. Find it when you need it.

KeepClip brings your recent clipboard items together in a compact Windows panel. Search copied text or file names, keep frequently used items in Favorites, and paste them into the application you are working in.

Your history supports text, images, and references to files and folders. Where available, the source application's name and icon help you recognize each item. Open the panel with Ctrl+Shift+V, or enable Win+V in Settings, then choose an item with your mouse or the arrow keys and Enter.

Choose a light, dark, or system theme and one of eight color palettes. Configure launch at sign-in, a copy confirmation sound, and optional copy on selection for read-only text exposed by compatible applications.

History stays on your device, with no in-app account and no cloud synchronization. KeepClip does not encrypt history: pause capture before copying anything you do not want saved.

History is limited to 200 items and 250 MiB of content counted by the app. File and folder references require the originals to remain available. OCR and HTML formatting are not supported. Pasting into elevated applications may require a manual Ctrl+V.

The app interface is currently in Italian. An English Store description does not change the app's interface language.

## Features

- Local clipboard history for text, images, files, and folders.
- Search copied text and file names.
- Favorites with a dedicated filter.
- Mouse and keyboard controls.
- Source application information, where available.
- Light, dark, and system themes with eight color palettes.
- Pause capture from the notification area.
- Configurable launch at sign-in and copy on selection.
